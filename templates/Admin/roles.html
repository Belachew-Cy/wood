Bindings

Roles bound to the chart

A binding hands a role to the seats of a unit at one rung, on top of each person's primary role, and it reaches every unit below the one it is stored on. Bindings are resolved on every request, so granting or withdrawing one applies from the next page and changes no account row. {{ department.bound_accounts }} of {{ department.accounts }} placed account{{ '' if department.accounts == 1 else 's' }} carry{{ '' if department.accounts == 1 else ' a' }} a bound role.

A binding on a unit also reaches its sub-units, so a directorate seat is granted once rather than repeated below it. The Administrator role is never bound; it already carries everything.
