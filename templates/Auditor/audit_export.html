Export Security and Data Protection

  • Only users with the existing audit export permission may generate exports.
  • Validate dataset names and formats on the server using an allowlist.
  • Apply the user's authorization to the underlying records before exporting.
  • Exclude passwords, tokens, credentials and other sensitive fields.
  • Store generated files outside the public static directory.
  • Use permission-checked download routes rather than exposing filesystem paths.
  • Record export requester, purpose, timestamp, dataset and result.
  • Apply appropriate retention and deletion policies to generated files.
