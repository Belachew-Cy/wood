Evidence Security and Handling

  • Only authorized audit users should upload or access evidence.
  • Validate file extensions, MIME types, file signatures and file sizes on the server.
  • Store uploaded files outside the public static directory.
  • Generate safe server-side filenames rather than trusting uploaded filenames.
  • Restrict evidence downloads through permission-checked routes.
  • Record uploader, upload date, file hash and related audit references.
  • Protect evidence against unauthorized modification or deletion.
  • Maintain an auditable history of evidence access and verification.
