Integration Security Controls

Read-Only Access

Audit connections must not modify departmental transactions.

Source Validation

Queries must use registered modules and authorized tables.

Credential Protection

Database credentials and sensitive records must remain protected.

Access Logging

Record relevant audit data-access activities.

Connection Monitoring Guidelines

  • Use the existing database connection provider.
  • Check each registered source independently.
  • Do not expose database passwords or connection strings.
  • Report connection failures with safe diagnostic messages.
  • Distinguish an unavailable database from a table that does not exist.
  • Do not automatically modify departmental database configurations.
  • Keep integration monitoring separate from departmental transactions.
