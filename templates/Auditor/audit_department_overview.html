Read-Only Integration Security

  • Audit Management retrieves information from registered departmental databases.
  • Departmental transaction records must not be modified by audit queries.
  • Database connections must use the existing connection provider.
  • Read-only database access must be enforced at the database connection level.
  • Only registered tables may be queried.
  • All data access must follow the existing Audit Management permissions.
  • Credentials, password hashes, tokens and other sensitive fields must not be exposed.
  • Unavailable data sources must be reported rather than silently treated as empty.
